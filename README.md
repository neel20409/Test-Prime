# TestPrime ⚡

> **Open-Source Computer-Based Test (CBT) Simulator & Automated Exam Generator for Indian Banking Exams (SBI PO, IBPS PO, IBPS Clerk, RRB, RBI Grade B).**

---

## 🎯 Key Features

- **Authentic TCS iON / IBPS CBT Console**:
  - Live 5-state color-coded question palette (*Answered, Not Answered, Marked for Review, Visited, Not Visited*).
  - Sectional countdown clocks with auto-submit and lock.
  - Dual viewing modes: Authentic Examination Mode & Dark Mode.
  - Bilingual interface (*English & हिन्दी*).

- **Linked Question Sets (Q1–Q4)**:
  - Top Reference Paragraph / Seating Arrangement Puzzle / DI Table stays pinned at the top.
  - Specific questions and 5 standard banking MCQ options (`A`–`E`) shift smoothly below with keyboard shortcuts (`1`–`5` or `A`–`E`).
  - Standalone questions transition cleanly starting at Q5.

- **100% Inbuilt Offline Extraction Engine**:
  - Direct PDF / DPP upload and extraction via workerless parser.
  - Zero external API keys or cloud dependencies required.

- **Real-Time Negative Marking & Diagnostics**:
  - Standard banking scoring scheme (`+1.00 / -0.25`).
  - Sectional breakdown, accuracy telemetry, percentile estimates, and 20-second shortcut explanations.

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/neel20409/Test-Prime.git
cd Test-Prime

# Install dependencies
npm install

# Run locally
npm run dev
```

Visit `http://localhost:3000` to launch the simulator.
